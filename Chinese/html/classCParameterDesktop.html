详细描述

远程桌面的基础参数接口。包括基本参数（网络参数等）。 所有远程桌面插件的参数都应从此类派生。

使用远程桌面基础参数

  • 因为插件都有一些公共参数（例如：网络地址等），所以插件参数请从 CParameterDesktop 派生。
    class CParameterFreeRDP : public CParameterDesktop
  • 请在 COperate 派生类的构造函数中实例化参数。
    CParameterFreeRDP m_ParameterFreeRdp;
  • 调用 COperate::SetParameter 设置参数指针。
    int COperateFreeRDP::Initial()
    {
    qDebug(log) << Q_FUNC_INFO;
    int nRet = 0;
    nRet = COperateDesktop::Initial();
    if(nRet) return nRet;
    nRet = SetParameter(&m_ParameterFreeRdp);
    return nRet;
    }
  • 因为 COperate 实例运行在主线程中（UI线程），所以插件参数实例也在主线程中。
